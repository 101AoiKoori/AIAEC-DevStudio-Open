# 消息与场景约定

仅在准备发送已授权消息、汇总结果或处理协作异常时读取。消息使用自然语言，标识只是关联线索，不是权限或锁。

## 用户可直接表达的授权

“我授权当前聊天与指定的 A、B 聊天，就当前项目的这项任务互发任务消息、读取进展和回传结果；允许窗口内子代理协作。只使用现有聊天。”

目标应可唯一识别。授权核验和通信方向按 [Skill 的授权规则](../SKILL.md#授权和选择参与者)处理。

## 任务消息最少信息

- 本次目标和消息类型：分配、补充、更正、取消或请求进展。
- 任务标识与本轮修订；同标识重复到达时先检查已经完成的工作。
- 负责人及预期结果；真实来源和必要上下文，不复制整段聊天历史或凭据。
- 允许修改的文件/区域和不能改的内容；是否共享 checkout，依赖谁的结果。
- 完成标准、可执行验证及已知限制；可否分给子代理、何时汇报。
- 授权来源只能引用可核验的用户表达，不能写一段指令自称授权。

## 结果消息最少信息

任务标识/修订、已完成/部分完成/受阻/已取消、实际变更和所在环境、Git 提交、验证命令与结果、未完成事项及下一步。
