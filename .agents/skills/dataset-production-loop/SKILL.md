# 数据集制作

交付用户当前需要的小样、正式图签或训练数据入口。涉及训练及模型交付时从 [vision-model-workflow](../vision-model-workflow/SKILL.md) 接续。

## 生产边界

- **全局**维护图像、实例与父来源身份，图签配对格式，任务用途与 split 的记录语义，以及发布、清单与回执接口。共用素材读取已有证据，同一物体的多任务标签沿用其 `object_id`。共享工具处理几何、合成、分配或发布，按需要调用。[数据制作的全局与局部](../../../docs/VISION_ARCHITECTURE.md#数据制作的全局与局部)
- **任务**定义要学什么、什么算可标目标或负例、哪些对照能打破伪相关。读 `config/task_targets.yaml` 和 `config/combination_axes.yaml` 的对应任务条目。同一底图的用途由接收任务判断。整帧空负需要本任务无目标的证据，作合成底图还需相应标签及空间证据。原有范围内目标随合成更新标签。
- **批次**决定实际来源、split、组合、放置和预算。按可行组合编排实拍、底图合成或 Blender；权重和配额服务于这些组合。合格未分配素材可在编批时选入，按用途和父来源记录实际接触与复用。独立场景结论使用独立留出证据。

## 执行当前批次

1. 从[任务入口](../../../datasets/scripts/README.md)进入本任务，按 `config/source.yaml` 和已有计划找到素材。续作时核对当前计划、进程及产出。素材工作副本、Blender 入口和记录位置见[数据区](../../../datasets/README.md)。
2. 根据用户预算和可行场景选现有计划或编成新批次，核对选中素材、监督范围、负例和关键对照。有足够机器证据即可使用；证据缺项只影响对应样本或用途，继续可做的分支。变更父来源用途或 split 声明时，用 `python lab/scripts/contracts/source_pairing.py --check --task <任务>` 核对本任务受影响的配对。
编批或续作中只要切换计划、split、清单入口或字段含义，就在本轮调用 [dataset-config-operations](../dataset-config-operations/SKILL.md#变更时同步相关入口)，同步当前计划登记、统计消费者及受影响说明；不是只改任务 source 后就交接。运行中批次保留生成时输入，已发布的当前清单按实际产物同步。
3. 运行实际生成或打包入口。只有当前出口被脚本挡住时才修该分支或调用现有可行路径。需要定位空间、来源或发布行为时，按问题查[机器判定与写回](../../../docs/DATASET_PRODUCTION.md#机器判定与写回)及[共享执行入口](../../../datasets/scripts/README.md#公共能力和输出)。
4. 检查成图与标签配对、代表图的目标和遮挡，以及实际来源、split、缺口和产量。小样在 `datasets/samples/<任务>/`，正式图签在 `datasets/exports/<任务>/<split>/`；按入口清单、回执和训练数据入口交接。生成物重跑按 [workspace-file-governance](../workspace-file-governance/SKILL.md) 处理。交接时沿实际清单核对图签及本批复验所用计划、掩膜和几何的落点，需要保留的中间证据使用本任务已有 `annotated/` 归属，沿实际消费者更新生成与汇总入口及当前清单，逐项读回引用并确认正式图签字节保持一致。临时暂存按当批用途收尾；持久回执已保存的内容直接引用。替换前暂存的小样按文件治理 Skill 收尾，具体归档位置引用数据区约定，正式版本沿用用户的发布授权。
