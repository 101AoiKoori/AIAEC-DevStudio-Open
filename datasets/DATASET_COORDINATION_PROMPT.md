# V4 数据集协作启动提示词

以下文字供用户在需要启动或恢复 V4 协作时发送。保存文件不会创建聊天、发送消息或授予授权；是否创建和跨聊天通信以用户当次直接指令及工具能力为准。现有参与者和职责见[协作协议](DATASET_COORDINATION.md)。

```text
请依据 datasets/DATASET_COORDINATION.md 协调 AIAEC 工作空间 V4
数据集制作。先读取 AGENTS.md 和适用项目 Skill，核对当前工作树、
项目、工作目录、参与聊天和实际数据；不要从历史路径、数量或
对话摘要推断当前状态。创建聊天前核对现有参与者，不重复创建。

用户直接在 person、e_bike、fire、building_name_paper、
sign、waste_bin_state、waste_sticker、meter 八个任务窗口协商并
推动各自制作；车牌沿用省赛模型，不创建车牌数据集窗口。任务
窗口自行处理普通任务选择，不需要向协调方逐步审批。

设置协调镜像负责已授权参与者之间的消息传递、跨任务问题、
共享资源写者和同一 checkout 的 Git 操作；任务窗口在授权和工具
允许时直接向镜像提出具体问题。镜像按需查询权威配置、文档、
实际路径及必要证据，回复结论、范围和未知项，不把所有消息转发
给总控。总控窗口保留给用户直接讨论总体方向与决策；需要用户
决定的比赛事实或权衡交用户，不代替用户作决定。

全局文档整治窗口按 workspace-doc-governance 维护工作空间文档，
V4 文档与共享契约窗口处理 V4 专项需求和接口，资产与生命周期
窗口按请求支持素材来源与引用；共用文件先确定单一写者。只有
存在具体独立质量核验需求且用户授权时才增加核验窗口。各窗口
保留适用的子代理及文件、实验和交付治理约束。

每个初始任务说明职责、实际依据、可写范围、共享边界、阶段目标
和停止条件；携带用户直接授权的原文与可核验来源。接收窗口须
自行核验授权，无法核验时在本窗口交付，由获授权方读取。线程
创建是异步的，未就绪时等待，不因超时重复创建；项目相同不代表
必然共享 checkout。消息送达不代表执行完成，也不是文件锁。

各任务先按需求和逻辑确定目标特征、应打破的错误依赖及合理状态
组合，再查询来源和入口落实计划；不要求实拍逐一证明人为设计的
组合。实际来源、标签、测量和产出如实记录，设计权重不冒称实测
分布。每模型只有一次训练机会，重训或微调尚未确定。不安排常规
开发验证、模型验证或最终测试，不以模型验证结果安排重训或选模。
用户明确授权的有限素材、小样或代码契约测试按指定范围执行。
未测效果保持未知。训练以合成数据为主，同时纳入直接实拍，实拍应占相当比例；缺少标签的当前实拍按任务重建标注；
合成包括实拍或数字图片的图像处理合成、Blender 渲染及渲染图与实拍混合。
八任务 train 规模、状态组合与来源计划以 docs/DATASET_DESIGN.md
为准；初始 30/40/30，2026-11-15 起 fire、building_name_paper、waste_bin_state
用 20/40/40，waste_sticker、meter 用 10/40/50，person、e_bike、sign 保持
30/40/30；比例不是硬门槛，按来源和标签实际状态调整并记录缺口。
分别记录图像、实例、来源组与来源复用，计划不代表已生产。
跨任务选源、基底数量和预留父来源按 docs/DATASET_DESIGN.md
“组合选源与基底数量”执行，达到制作细则中的选源停止点就交接。
八项基底调查、区域和脚本规划已交接，
见 docs/DATASET_PRODUCTION.md 的“八项任务规划交接”。小样制作、
批量生产和训练当前暂停。预算结束不等于通过，未解决的关键缺陷
如实记录。

单张和批量生成前明文确定背景、目标、标注、增强组合、约束、
预算与输出范围；贝叶斯工具作为不可绕过环节是目标架构，当前
实现范围与不可行情况按 docs/DATASET_DESIGN.md 的“贝叶斯状态
组合与生成契约”执行，不将配额计划写成实际覆盖。
素材来源随机抽样、状态随机抽样与贝叶斯配额分别确定和记录；
配额工具不自动查询或随机选择来源。来源和合成方式的定义以
docs/DATASET_DESIGN.md 的“数据来源与生成方式的定义”为准。

协作消息只传必要问题、结论、证据位置、责任和未决事项；权威
文件及 Git 保存持久依据。工具不保证后台监听或自动转发；没有
请求时不反复追踪，不假定参与者收到消息就停止写入。用户未授权
时不自动启动大规模生产、训练、部署、素材删除或环境迁移。

完成启动后报告参与者的名称、职责、实际 thread ID、host ID、
项目、工作目录和状态，以及创建或通信失败项。窗口已创建不
代表数据集已完成。
```
