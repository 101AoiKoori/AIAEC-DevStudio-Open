# 人物立牌的遮挡识别与分组计数

**设计分类：固定图案与实例。** 近场观察图像 → 可辨正面立牌的类别及可见框 → 社区、非社区分别计数。主体是赛场立牌，已确认的白背可用于难负例，身份不可判的残片按范围处理。

**验证问题。** 在既定停点和原图尺寸内验证单次检测能否维持逐类计数，同时压制白侧边和车辆遮挡引起的误报与漏检。


## 定义与作用范围

本任务在 A/B 街指定观察点定位实体人物立牌，输出其可见框和社区／非社区类别。VisualRecognition 的现行定义把任务目标限定为车前近处的一组可辨立牌，后排排除，可见框高小于原图画高 20% 一律排除。达到 20% 的立牌仍须满足近处、前排和印刷正面可辨。街区总数由分街覆盖和实体去重得到，逐图推理只提供候选及类别。国赛 V4 数据采用较宽的监督范围，仍可辨的远景可作检测正例，现场过滤在识别之后另行考虑。查 DevStudio 的 [人物要求](../../lab/features/person/README.md) 和 VisualRecognition 的 `person/task.yaml`。

## 正例与反例

| 观察 | 处理 |
| --- | --- |
| 前排两张人物立牌，一张被电动车挡住下半身，但印刷身份仍可辨 | 两个正例，分别标可见框和类别。按 VisualRecognition 口径检查原图框高 |
| 同图含近处可辨正面与只显白背的立牌 | 只标正面，白背留在图中作同框干扰 |
| 真人人体、空场、彩色薄侧或窄亮边 | 均可作为拒识对照，保留能揭示误报的真实背景 |
| 后排可辨正面、同一立牌在邻帧再现 | 前者按现行范围排除，后者在分街汇总中按同一实体去重 |

## 核心问题与可观测证据

从成像出发，类别证据来自印刷面，实体证据来自立牌轮廓、厚度、支撑和前后遮挡。人物形状可同时来自真人和立牌，纯侧视产生的窄高反光也可能像一个检测框。格式塔的图底分离和轮廓连续性提供案例分析视角，例如被车身遮断的印刷面可由剩余区域判断归属，两个相接的正面仍应分成两个实例。前后位置和有效画高属于任务边界，与能否认出印刷图案分别核对。 [Wagemans 等，2012](https://pmc.ncbi.nlm.nih.gov/articles/PMC3482144/)

## 数据与方法设计

- 直接实拍保留逆光、纸板边缘反光、压缩模糊以及人与车的真实遮挡。正面、白背、真人、纯薄侧和遮挡后的部分正面分别记录。旧合成回放先按当前可见范围筛选，防止薄侧仍带旧正框。
- Python 用已知身份的立牌裁片放到实拍或 Blender 底图，按脚点、距离和透视控制尺度。前景车辆需要实际盖住部分正面，并用剩余可见区域生成框。把车辆放在背景层只会得到人与车同框。固定图案与背景变化分开记录，父视频的派生图跟随父来源。
- Blender 底图用于组合不同机位、路面、阴影和背景。补拍承担材料和曝光差异的核对，尤其是暗光下的非社区正面和带颜色的真实薄侧。Copy-Paste 提供遮挡合成的参考，域随机化提供变化采样的依据。 [Ghiasi 等，2021](https://arxiv.org/abs/2012.07177) · [Tremblay 等，2018](https://arxiv.org/abs/1804.06516) · [V4 数据制作入口](../../datasets/scripts/person/README.md)

## 历史与当前

**DevStudio 历史。** V4 完成 3,000／300／300 图签、150 轮基线和 10 轮白侧板窄亮边微调。在 53 张已知开发图的历史配对回归中，TP=83、FN=6 保持，FP 由 29 降到 4。随后尝试切片复核、真人辅助分支的收益要结合新范围解释。对明确排除的后排目标继续切片追召回，会增加运行成本和重复框机会。 [V4 阶段报告](../research/DATASET_MODEL_REPORT_20261119.md)

**VisualRecognition 当前（2026-11-21）。** 用户确认人物识别问题已解决。当前方向收敛为指定停点、整图 640、单次检测。V21 从 V20 数据补入 5 张人工标注实拍和 100 张审过的近场遮挡合成图。在置信度 0.70 的 99 张固定原图回归中，现用 v001 的两类计数全对为 91/99，第 41 轮检查点为 97/99（169 TP、1 FP、1 FN）。新增 11 张原图达到 33 TP、0 FP、0 FN。当前现场仍登记 v001。第 41 轮及其约 6.26 MB 的精简版均登记为离线候选。证据见 VisualRecognition 的 `person/STATE.md`、`person/models/v001_narrow_edge_10ep/model.json` 和 `person/experiments/v014_person_vehicle_occlusion_finetune/r001_v001_strict_mix/`。

## 障碍、取舍与验证

一次整图推理降低了计算、维护与多分支合并成本，代价是更依赖停点覆盖和近处正面的像素尺度。V21 的固定回归覆盖两类计数、真人、薄侧、白背、远处与空场，其中部分照片与训练或验证同源。新增 11 张压缩包原图复测与回归子集字节相同，支持独立加载的结果一致性。整街验收还需分别检查 A/B 街分段覆盖、两类框匹配、非社区人员框图和跨观察点去重，以察觉最终计数中误报与漏报的抵消。
