# 八项视觉识别任务设计

本专题按**输出所需的物理证据**分组，每项任务独立成篇。八项对应 [V4 学习目标](../../config/task_targets.yaml)。各篇依次说明定义与作用范围、正反例、可观测证据、数据与方法、历史与当前、障碍与验证。读完一篇应能判断一张图该怎么标、输出如何消费，以及方案在哪些条件下已验证。

## 从物理事实到可验证输出

先明确比赛环节实际需要的结果，例如逐类人数、逐楼火焰计数、逐桶开闭状态或实际读数。逆向追问三个问题。这个结果由什么物理事实决定？相机在给定距离和视角下能看到哪些证据？哪些遮挡和成像条件会使这些证据不足？计数所需的是可区分的实例，归属所需的是实例同载体之间的空间关系，测量还需要标定与刻度语义。先隔离这些变量，再决定用框、关键点、读数步骤或场景约束来表达。

格式塔的图形–背景和知觉分组可用于组织失败案例。相邻两块红色图案可能被误并为一块，遮挡后的轮廓延续可能把两辆车误连在一起，白色纸边可能从背景里被分离成假目标。对照应保留与真实物理对象一致的边界，检查邻近、连续和相似等线索何时支持实例识别，何时促成混淆。这里借用的是分析语言，模型依据需要从受控样例和实际错误中验证。[知觉分组综述](../research/VISION_TASK_REFERENCES.md#知觉分组与捷径学习)

## 实拍、渲染和合成如何配合

单靠平面图案变换难以重建真实纸张的折痕、自遮挡、反光与投影。拍摄距离、快门和相机处理还会共同改变最后落在传感器上的证据。项目采用三类互补手段，在目标条件下用实拍检查模拟差距。

| 手段 | 用在什么问题上 | 主要成本与边界 |
| --- | --- | --- |
| 场地实拍及复核 | 保留真实材质、打印和粘贴形态、车载曝光、压缩与现场干扰物。用于定位真实失败及建立回归样例。 | 受场地和时间限制。相邻视频帧便于复盘，独立评估仍需按来源分组。 |
| Blender 渲染 | 控制实体姿态、遮挡关系、表面形变、相机轨迹及投影，并输出可定位到实例的掩膜。 | 建模、布光、渲染和校准耗时。模拟中的材质参数与传感器假设需要真实样例核对。 |
| Python 图像处理与混合合成 | 在实拍墙面、桶体、路面上快速替换图案和位置，按同一几何变换生成标签。需要时把渲染前景与阴影放入实景底板。 | 二维透视适用于近似平面。弯折、前后遮挡与贴地效果需要额外几何或独立掩膜，接缝和错误阴影可能变成训练捷径。 |

组合按失败问题安排。同一底图换类别、同一类别换光照或尺度、同一实体切换状态，分别检查标签与背景、颜色、位置的伪相关。优先覆盖实际会经过的视角和距离。若机位稳定且关键证据清楚，固定观察范围、局部裁块或一次检测就可能满足需求，代价是范围要现场标定，机位变化后要回归。遇到跨视点遮挡、强反光或目标只剩几像素时，再按失败类型决定是否追加视角、补拍或改数据，避免把有限算力花在和输出关系薄弱的视觉细节上。[渲染、合成与成像参考](../research/VISION_TASK_REFERENCES.md)

标注区分可确认的反例、整帧确认无目标的空负图，以及证据不足的待定样例。训练和评价分别追踪父图、视频或母场景，记录同源增广与独立真实留出。先统计漏检和误报，再看类别、归属、整图计数或读数误差。同一样本上的历史对照记录权重、阈值、分母和适用机位，置信度单独解释。[组合轴配置](../../config/combination_axes.yaml) · [数据制作与记录](../DATASET_PRODUCTION.md)
