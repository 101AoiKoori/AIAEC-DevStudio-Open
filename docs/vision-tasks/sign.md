# 禁行牌具定位与路线决策输入

**设计分类：固定图案与实例。** 路口观察图像 → 牌具可见框与可靠状态 → 结合标定位置供导航选择路线。检测单位为牌面、立杆和底座组成的单一牌具。

**验证问题。** 将牌具定位质量、观察位置归属和实际路线选择分开验证，重点记录低反差背面、近景截断和普通立杆。


## 定义与作用范围

裁判赛前将禁止直行指示牌放在两个候选位置之一。视觉从观察点图像定位牌具，返回可见框、画面位置与可靠状态，供路线决策读取。牌面、立杆和底座组成同一个物理实例，标注类别统一为 `sign_fixture`。位置与路线分支的对应关系由现场标定，识别结果不可靠时，由导航停车并记录故障。赛题条款与输出约定见[任务需求](../../lab/features/sign/README.md)。

## 正例与反例

| 观察画面 | 标注或结果 |
| --- | --- |
| 正面、侧面或背面的完整牌具，牌面内容未必可读 | 一个牌具框，包含实际可见的部件 |
| 画面边缘截去牌面，剩余立杆与底座的结构能确认其身份 | 只框可辨的可见部分 |
| 同一机位只有普通信号杆、立柱或单独的圆形物体，观察范围内确认无牌 | 空标签，可作硬负例 |
| 只有一段无特别特征的杆，或候选摆位未纳入取景 | 标注或决策保留未知，待取得可辨证据 |

## 核心问题与可观测证据

从路线决策反推，所需信息是已确认身份的牌具与观察位置。对检测器而言，判别依据包括连在同一轮廓上的牌面、杆和底座，接地关系，以及斜视和截断后仍保留的结构。用格式塔的连通与连续性解释这些线索，可以明确哪些部件应归为同一实例，以及何时部分信息仍足够。路口背景、默认位置和红色圆形只能提供上下文。一旦模型把它们当成身份线索，换摆位、背视或遇到普通杆时就会失效。

## 数据与方法设计

- **保留物理证据。** 从实拍取正、侧、背等有证据的牌具裁片，连同掩膜保留杆宽、底座轮廓与材料反光。直接实拍补足运动模糊、低照和壁面遮挡。固定同一牌具换位置和取景，可以检验模型是否仍依赖背景。
- **控制组合。** Python 合成在路口实拍上按可行落点和成像尺度放置前景，构造近远、截断、遮挡与明暗对照。杆末端与底座细，裁切后的框由实际可见部分决定。Blender 可以为共享场景提供机位、透视和接地光影的补充，国赛这项主线采用真实牌具视面加真实背景以减少重建成本。普通杆和对应机位的确认空场进入负例。
- **记录输入来源。** 目标、背景和干扰可有不同父源，按视频和采集场次跟踪其复用。通过组合轴扩大变化范围，合成后核查是否依然具备身份线索。具体入口见[禁行牌数据制作](../../datasets/scripts/sign/README.md)。

Tobin 等的域随机化研究为改变机位、照明、背景和干扰提供方法依据。Ghiasi 等的 Copy-Paste 实验支持用实例掩膜组织合成。本任务还需单独核对接地、杆的可见性和普通杆误报。 [Tobin 等，2017](https://arxiv.org/abs/1703.06907) · [Ghiasi 等，2021](https://arxiv.org/abs/2012.07177)

## 障碍、取舍与验证

牌具尺寸小且杆结构通用，扩大合成量的收益取决于场景与干扰是否真正多样。现有 V4 测试支撑其覆盖范围内的检测表现，普通信号杆、低机位截断和路线门控仍需分别验证。现场按两个位置记录物体检出、位置判定、普通杆误报，以及看不全或识别失败时的停车结果。固定机位连续帧应按采集段汇总相关性，避免把同一次摆放当作多次独立试验。
