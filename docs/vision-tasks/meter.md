# 双针温湿度仪表定位与读数

## 定义与作用范围

**分类：部件关键点定位与物理量估计。** 输入是站房任务点的相机图像，目标是同一仪表的温度和相对湿度。双针 Pose 以一个表盘框、两组各四个点表达观察结果。每组依次涉及该针的轴心、针尖、所属量程的两端。两项分别记录点可见性和读数状态。温度、湿度的单位、量程与弧向来自标定配置。独立推理包以温度 −30～50 °C、湿度 0～100 %RH 作为已记录配置。跨工作区的点序以各模型配置为准。VisualRecognition 同目录下另有数字电表屏幕框研究，属于不同可观测量。 [任务矩阵](../TASK_MATRIX.md) · [DevStudio 读数配置](../../lab/features/meter/inference/config/pose_readout.json) · [VisualRecognition 仪表定义](https://github.com/101AoiKoori/AIAEC-VisualRecognition/blob/main/meter/task.yaml)

## 正例与反例

| 画面 | 判定及原因 |
| --- | --- |
| 正对目标双针温湿度表，两个轴心、针尖和各自刻度端点清晰 | 检出一个表盘并分别读温度和湿度 |
| 另一种盘面颜色，结构与量程一致 | 色彩可变化，按指针与刻度的几何关系读数 |
| 湿针被玻璃眩光盖住，温针及其端点可辨 | 表盘仍是正例，报告温度估计，湿度保留未知 |
| 无目标的圆形路标、单针压力表、数字电表屏幕 | 均不能作为本双针读数任务的完整正例 |
| 两针可见，但针线几何退化或针所指落入无量程的空白弧 | 保留检测证据与失败原因，相关读数未知 |

## 核心问题与可观测证据

读数的第一性问题是从相机投影恢复可与刻度标定比较的针向。模型先回归每一针的轴心、针尖及所属量程端点。以轴心为原点，计算从量程起点到针尖的**有向角**，再除以量程起点到终点的有向跨度，得到量程比例。在等角度、已知弧向且投影近似正对的条件下，可用该比例对上下限做线性内插。空白弧、短到无法定向的针向量、低置信度点或不可见的端点会破坏这条推理链。

从格式塔的良好连续性看，针是从轴心伸向刻度的连续结构，针尖与轴心必须归属于同一针。重叠双针、装饰线、刻度线和表盘印字都可能呈现相近的细长边缘。倾斜投影改变表盘形状与图像角度，图像坐标下的等角度读数会出现系统偏差。Zhang 的平面标定给出用多个平面视图估计相机参数与径向畸变的依据。GAUREAD 把表盘定位、透视校正、针检测和刻度重建逐步分解。本项目据此区分定位证据和读数证据，并按固定道具场景决定是否承担逐帧校正与刻度重建的成本。 [Zhang，TPAMI 2000](https://www.microsoft.com/en-us/research/publication/a-flexible-new-technique-for-camera-calibration/) · [GAUREAD，Milana 等，Sensors 2022](https://www.mdpi.com/1424-8220/22/17/6681)

## 数据与方法设计

- **实拍提供物理参考。** 对焦、运动模糊、玻璃反射、逆光或饱和，以及湿度针像素长度由真实相机、材料、机位和照明共同决定。实拍按拍摄段记录盘面颜色、两针是否可判、参考读值及可见点。固定读数的视频可以覆盖距离及视角，不能代表不同读值。
- **Blender 控制几何与照明。** 批量改变两针位置、盘面外观、相机俯仰偏航、距离与照明，使用已知几何投影同步八点。白盘、彩盘同几何配对可检查模型是否依赖颜色；还要观察不同亮暗、真实高光和玻璃眩光是否在目标相机中同样出现。
- **Python 合成补齐构图。** 透明渲染前景可与实拍或 Blender 底图组合，变换须同步更新框和点位，独立安排空场及相似圆形反例。对表盘图形的平面变换能覆盖受控透视，真实反光、遮挡与镜头动态范围仍需实拍。镜像会破坏文字和盘面刻度的方向。训练和验证可复用固定表盘几何以诊断赛场道具，但结论应标清共用父来源。 [DevStudio 数据构建](../../datasets/scripts/meter/build_full_dataset.py) · [文献索引](../research/VISION_TASK_REFERENCES.md)

## 障碍、取舍与验证

在已知表型、固定观察点和有限算力下，用一个小型 Pose 模型加等角几何，可以减少逐图 OCR、逐刻度检测和透视匹配的运行成本。若斜视导致偏差，先比较现有任务点的正对采集和标定重投影误差，再决定是否承担更复杂的校正。表盘玻璃反射可使另一支针仍判读成功，因此两个输出应分别记录有效性。

阶段报告的 Test Pose mAP50–95 为 0.99320。该批 971 个可测实例的温针投影角平均误差为 1.91°，湿针为 10.52°。整体定位指标与湿度针角误差需要同时看。验收应逐针报告检测覆盖、像素和角度误差、与实物参考读值的差值、按规则允许区间的命中率，以及双项完整正确率。用真实任务机位分别留出正视、斜视、眩光、遮挡和量程端点样例，按拍摄段统计。若只验证了一段同读值视频，结论限于该读值和该段条件。 [仪表专项指标](../research/DATASET_MODEL_REPORT_20261119.md#任务效果与微调结论)
