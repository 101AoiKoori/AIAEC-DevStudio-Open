# 垃圾桶逐实例定位与盖态判断

**设计分类：实体姿态与开闭。** 近景四桶原图 → 整桶框 → 原图桶口局部证据 → 每桶开、闭或未知。桶色及最终投放判断由对应步骤处理。

**验证问题。** 在固定机位下检查保留桶口像素能否改善盖沿判态，同时分开报告漏桶、背景误框和开闭错分。


## 定义与作用范围

在垃圾桶 waypoint 停车并正对近景四桶，逐桶输出可见桶框及 `open` 或 `closed`。现场侧另行根据桶色判定垃圾桶类别，并接收垃圾贴纸任务的结果来判断投放。盖态在遮挡或过渡时不可判，保留桶实例及未知状态。现场主线面向规定机位的近景桶，远处小桶超出这套机位策略的验证范围。 [任务需求](../../lab/features/waste_bin/README.md) · [VisualRecognition 任务定义](https://github.com/101AoiKoori/AIAEC-VisualRecognition/blob/main/waste_bin_state/task.yaml)

## 正例与反例

| 观察画面 | 标注或结果 |
| --- | --- |
| 红桶盖离开桶沿，看到内侧或桶口 | 定位红桶，状态为开 |
| 同一红桶盖与桶沿重合且覆盖桶口 | 定位红桶，状态为闭 |
| 桶体可定位，旁桶或视角遮住全部盖口证据 | 保留桶框，盖态未知 |
| 设备外壳、方箱或靠近桶排的空地 | 对这些区域不输出桶框。整个有效范围没有桶时可作空负例 |

## 核心问题与可观测证据

定位与判态有不同的像素证据。桶体边界和接地位置用于定位，盖板与桶沿的相对姿态、两者间的可见空隙、盖板遮住桶口的连续边界用于判态。格式塔的轮廓连续性和遮挡关系可解释低角度下容易混淆的情形。亮斑会改变桶口明暗，开盖投影也可能被邻桶吞并，因此单凭暗区、颜色或桶在四桶中的顺序无法确认状态。检测器报出空地框时，状态头仍可能给出开闭分数，需分别评价定位与开闭。

## 数据与方法设计

国赛 V4 用 Blender 做四色桶开／闭、单桶／多桶、顺序、视角和不同光照的可控组合，保留盖板转动和遮挡。Python 将带掩膜的前景放入确认可用的场景，核查桶底接地和背景中已有桶的标签。实拍保留了桶口塑料反光、真实透视、接缝与邻桶遮挡，用于低机位和近距离小车视角检验。范围内主体桶画面优先按直接目标样本使用，整图空负例须有空场证据。 [桶开闭制作入口](../../datasets/scripts/waste_bin_state/README.md)

VisualRecognition 现场路线先定位单类整桶，在原图按桶框裁取顶部约 55%，带少量横向与上方上下文，随后缩放为 160×160 判状态。保留原图像素有助于观察细盖沿。He 等在 Mask R-CNN 中以 RoIAlign 保持区域和空间特征对齐，提供区域任务对空间精度敏感的技术对照。此处运行的是原图裁块方法，另有冻结特征和联合训练的对照实验。 [He 等，2017](https://arxiv.org/abs/1703.06870) · [VisualRecognition 任务状态](https://github.com/101AoiKoori/AIAEC-VisualRecognition/blob/main/waste_bin_state/STATE.md)

## 历史与当前

- **DevStudio 国赛历史。** V4 两类 YOLO 直接输出开／闭整桶框，完整基线 3500/186/253 张。把 Train 换为 804 张真实桶主导输入并微调后，253 张相同 Test 的整图全对由 225 降至 193，额外预测由 2 增至 43，候选未替代基线。 [阶段报告](../research/DATASET_MODEL_REPORT_20261119.md)
- **VisualRecognition 现场方案。** 两种桶口裁块训练（仅实拍、实拍加 58 张 Blender）在同一段留出视频均定位和判态 92/92，严格四桶均 23/23，早期两类 YOLO 与联合训练均为 22/23。现场 v002 保留仅实拍状态头，固定机位先按区域过滤，超过四框时按桶底位置与框高的一致性筛选四框。后续 v004 试用包使用补入 51 张多背景空图重训的单类检测器，保留原状态头。在 18 张来自另一 waypoint 采集组的空图中，旧检测器的 20 个误框降为 0，原留出视频仍 23/23，补充的 5 张近景图也全对。实际现场历史误报截图缺原帧，v004 尚不能在该帧验证。 [VisualRecognition 任务状态](https://github.com/101AoiKoori/AIAEC-VisualRecognition/blob/main/waste_bin_state/STATE.md)

## 障碍、取舍与验证

固定停车机位限制了识别空间，选四桶可以抑制孤立设备误框。排序只能在候选框数超过四个时使用，不能补回漏检的桶，四框数量也不能单独保证四个实例均正确。现场测试应区分错框、漏框、盖态错和整组成功率，另查空场、低机位开盖和红灰桶的难例。23 张留出帧来自同一视频，因此 23/23 的结果支撑该段复测。现有 58 张渲染样本没有在相同留出中体现增益，重建背景和盖板的成本应与新独立场次中的误差一起衡量。
