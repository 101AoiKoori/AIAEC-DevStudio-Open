# 垃圾物品贴纸识别

## 定义与作用范围

定位纸卡并区分 24 类赛题指定物品图案。现场关注桶正面下方的白底纸卡，每桶一张。训练可使用独立实体纸卡和其他载体，联调时另按位置关联纸卡和桶，再由物品类别和桶类别映射判投放对错。桶身固有分类图标、桶色和盖态分别有自己的含义。 [任务需求及物品映射](../../config/perception_tasks.json) · [数据制作入口](../../datasets/scripts/waste_sticker/README.md)

## 正例与反例

| 观察画面 | 标注或结果 |
| --- | --- |
| 桶正面下方可辨别的苹果纸卡，或换到另一色桶上的同一苹果纸卡 | 贴纸框与苹果类别保持一致，桶归属另记 |
| 桶身只见固有分类标志，或者同位置贴一张空白卡 | 贴纸分支不报物品框，确认无其他目标后可作空负例 |
| 斑马线、背景白块或实物塑料瓶 | 不属于指定物品纸卡 |
| 纸卡因反光、遮挡或缩小到无法确认是纽扣电池还是其他图案 | 类别未知，保留复核，不能按空负训练 |

## 核心问题与可观测证据

物理纸卡包含载体边界和印刷内容两层信息。边界定位置，内容定物品，纸卡与桶面的接触和相对位置支持归属。用格式塔的图形与背景关系看，白底能聚合纸卡区域，图案要在该区域内与白纸区分。远距离下，茶渣和纽扣电池的小纹理、白边被截断后的纸卡、反光后的浅色图案都会削弱这层分离。固定桶色、白矩形和相同桶面反复与某类共现时，模型可能借它们完成标签预测，导致白线误报和换桶错分。 [Geirhos 等，2020，捷径学习](https://arxiv.org/abs/2004.07780)

## 数据与方法设计

- **从实体与视角定义像素。** Blender 在桶面轮换 24 张图案，让相机沿真实可行的轨迹变化，控制纸面粗糙度、局部高光与投影。图案 Alpha 用于让印刷内容与纸白混合，实体纸卡仍为不透明面。历史透明剪影候选只逼近物品轮廓，会丢掉白边和纸卡形状。实际纸张弯折、相机曝亮和桶面印刷叠盖仍依赖实拍核对。
- **保留桶面与纸边。** Python 可把真实纸卡投影到已确认无独立物品贴的真实桶面，用桶面四边形、纸面宽高比和位置确定透视，容许真实纸边盖住固有标识的下沿。对照使用同图案换桶色、同桶换图案、同位置换空白纸卡。单贴裁图有类别监督，整场检测还需目标坐标和无目标背景。
- **按输入与用途评估。** 真桶底图的拍摄组与裁图父家族分别追踪。换视角渲染评估覆盖范围，按纸卡像素尺寸和背景记录误差。工程验证可以快速排查图签、尺度和类别，停车实拍用于检验端到端效果。 [制作与来源说明](../DATASET_DESIGN.md#垃圾贴纸数据设计) · [VisualRecognition 任务状态](https://github.com/101AoiKoori/AIAEC-VisualRecognition/blob/main/waste_sticker/STATE.md)

## 历史与当前

- **DevStudio 国赛历史。** V4 以独立纸卡、贴桶合成和场景负例训练单模型 24 类 YOLO，基础 Train/Val/Test 为 1800/240/240 张。在 360 张挑战 Test 上，保召回微调使 FP 从 162 降到 31，同时 TP 从 575 降到 573。专项结果主要说明该挑战范围内白色干扰的得失。 [阶段报告](../research/DATASET_MODEL_REPORT_20261119.md)
- **VisualRecognition 渲染与训练对照。** v008 的相机主要在固定朝向附近小幅平移，v009 使用相机关键帧覆盖 −15° 至 +15°，保留两个版本的 2100/300 张规模。v009 微调在该 300 张验证图的 mAP50–95 从 86.80% 到 99.43%，真实正例只有一张四贴图。停车 P23 旧、新权重均为 4/4，路线诊断 20 个真框中的正确数从 14 降至 9。旧 best 继续作为默认对照。原图按人工桶框裁出下半部时，旧 best 在相同路线图上的正确数从 14 到 18，误报（含错分）从 14 到 5。自动桶框裁区还需实测。
- **VisualRecognition 当前设计。** 已选择真实纸卡与真实桶面合成完整框监督，再以单模型 YOLO 原生微调。本地 v002 在 v001 纸卡偏小后按实拍比例重新定位制作，已产出 299 张 Train 和 83 张工程 Val，960 输入下纸卡短边中位数从 22.1 增至 37.8 像素。其验证隔离了底图拍摄组与裁图文件名家族，现场停车样本独立冻结。该数据尚未训练，现用权重没有由此替换。 [VisualRecognition 任务状态](https://github.com/101AoiKoori/AIAEC-VisualRecognition/blob/main/waste_sticker/STATE.md)

## 障碍、取舍与验证

相机轨迹和材质拟真可便宜地生成类别组合，但改善合成验证分数后仍要看实拍的类别混淆、纸卡漏检和白块误报。复用已有真实桶面和实体纸卡能降低三维重建与补拍成本，也使可用贴面和独立父来源成为数据容量的约束。现场优先比较同一停车图上的逐类正确数、漏检、误报和四贴齐全率，再拆分定位、类别、归属及投放判定。用桶框裁图能缩小白线干扰范围，需另计桶框偏移导致纸卡被裁掉的代价。
