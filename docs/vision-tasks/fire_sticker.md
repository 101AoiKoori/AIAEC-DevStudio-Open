# 火焰贴纸检出、楼体归属与计数

**设计分类：载体与空间归属。** 楼面图像 → 可见火焰贴纸框 → 匹配楼体 → 按楼汇总。楼面可见范围不足时，整楼计数保留未知。

**验证问题。** 将红黄灯和红桶等相似物误报、重复框、小图案漏检、所贴楼体的归属错误拆开检查。


## 定义与作用范围

本任务检测赛题指定的印刷火焰图案，逐张输出其可见框。DevStudio 的数据任务键为 `fire`，类别为 `fire_sticker`，VisualRecognition 使用 `fire_sticker` 作为任务键。现场报数还需要建立贴纸到楼面的归属，并记录该楼实际观察覆盖。某可判别楼面为空可以得到该面的零值，尚未看全的整楼保留未知。查 [DevStudio 任务定义](../../lab/features/fire/README.md) 与 VisualRecognition 的 `fire_sticker/task.yaml`。

## 正例与反例

| 观察 | 处理 |
| --- | --- |
| 一栋楼两个可见立面各贴一张指定图案 | 分别给框，记录可确定的楼面和楼宇归属 |
| 指定贴纸很斜，局部可见仍足以确认图案 | 保留贴纸正例，单列小像素和大视角诊断 |
| 红灯、红桶、橙色面板、非指定图案、真实火焰或烟雾 | 均可作硬负例，与正例同框时继续保留正框 |
| 镜头只拍到无贴的局部墙面 | 记录该裁区无贴和楼面覆盖不足，整楼数为未知 |

## 核心问题与可观测证据

成像中最直接的证据是印刷火焰图案的形状和内部结构。红橙色同时来自灯、桶和其他道具，实际斜视会压缩轮廓并让纸边、图案与墙面纹理混在一起。按格式塔的图底分离理解，同一立面是空间载体，贴纸轮廓与内部火焰是目标。楼面连续性和立面边界有助于判断归属，跨楼邻近的贴纸也应逐实例记录。 [Wagemans 等，2012](https://pmc.ncbi.nlm.nih.gov/articles/PMC3482144/)

## 数据与方法设计

- 直接实拍保留纸面高光、墙面纹理、运动模糊及实际采集噪声。组合同框的红灯、红桶与真贴图，避免模型把高饱和度或桶的位置当成目标条件。
- 对可配准的实拍墙面，以墙缝和边界建立平面坐标，把贴纸用单应矩阵投影进同一立面。转角的相邻两面分别登记。Python 合成便于改变图案位置和数量，也能以低成本覆盖已知干扰，纸的厚度、翘起和投影随三维形状变化时需额外材料证据。
- 完整 Blender 分支联动相机、立面、贴纸尺度与地面；混合分支拟合相机，将带阴影的楼体图层在线性光空间与实拍底图合成。实例 ID 图用于复核最终可见框。它能扩展难拍的机位和贴数，域随机化论文提供合成变化的依据。固定图案、母工程与视频父来源单独记账。 [Tremblay 等，2018](https://arxiv.org/abs/1804.06516) · [V4 数据制作与几何检查](../../datasets/scripts/fire/README.md)

## 历史与当前

**DevStudio 历史。** 直接实拍、实拍墙面贴图、完整 Blender、楼体加实拍背景支撑了首轮 3,000／300／300 图签。随后用 1,224 张精简 Train 微调 10 轮。在历史 300 张 Test、640 输入、0.25 阈值下，TP 从 475 增到 480，FP 从 9 降到 4。事后把同一批预测筛到 0.50 时，红桶误报归零，仍漏两张小贴纸并保留其他误报。提高阈值的代价可据这组结果观察。 [V4 阶段报告](../research/DATASET_MODEL_REPORT_20261119.md)

**VisualRecognition 当前（2026-11-21）。** 现选 `v002_compact_finetuned`，是从原 compact 出发增加 4 张实拍与 3 张 Blender 回放的 r004 Last 快照。主路线实拍检查覆盖 97 张，7 张已有图签。0.50 下已标图的漏检从 18 降到 16，新增检出来自同一张运动模糊帧。斜视对照三份权重均为 4/4，正面均 7/7，已检查的红桶和红灯区域无误报。其余 90 张作预测对应检查。较极端合成斜视仍漏多，按用户决定以车载实拍作为后续判断依据。证据见 VisualRecognition 的 `fire_sticker/STATE.md` 与 `fire_sticker/experiments/v001_capture_prelabel/r008_checkpoint_selection/report.md`。

## 障碍、取舍与验证

运动模糊、极小投影与大斜角会稀释图案结构，分数变化应结合逐实例匹配和视角分层判断。四分支生成有助覆盖训练空间，扩大到大斜角需要更多渲染、复核和实拍验证成本。当前实拍选型只在少量带标签帧上找到具体收益，极端合成诊断保留为压力测试。模型回归记录红橙干扰误报、同图漏检和重框。逐楼验收还要验证楼面归属、漏看立面和重复经过同一贴纸，分别报告逐框、逐面与整楼结果。
