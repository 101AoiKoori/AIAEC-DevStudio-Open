关键点置信度加权与分段插值可以作为候选算法思路，但原项目“透视鲁棒”不能理解为任意透视角下都精确。以其原读数函数做无图像的合成坐标小实验：理想圆上的指针预期值 2.25，保持水平比例时得到 2.25；将水平坐标压缩为原来的 0.4 后得到 2.28。该实验仅说明某种斜视下角度插值会产生误差，不是比赛精度评估，也未验证模型对真实图片的检测效果。

该历史实验使用外部读数函数；其源码许可尚未确认，当前没有可分发的工作区内独立实现，不能直接复现。确认许可并完成工作区内独立适配后才可继续对照。

## 2. 可比较的开源参考

- [Intel OpenCV 仪表读取示例](https://github.com/intel-iot-devkit/python-cv-samples/blob/master/examples/analog-gauge-reader/analog_gauge_reader.py)：源码声明 MIT；通过圆和线等几何方法读取指针，标定量程与角度，适合做固定表盘的轻量基线。代码依赖手工标定且以单表/单针思路为主，多表心和透视需另做。
- [gauge-ai-reader](https://github.com/Jason-Shell/gauge-ai-reader)：README 描述用四个关键点和角度换算压力表的 bar/psi 两套刻度，并提供 ONNX 等方向。这里的“双刻度”是一根指针对应两种单位，不是比赛的两根针；仓库源码许可在本次查询中未确认。可以参考四关键点标注与离线评估组织，不直接采用其模型或读数映射。
- [analog-gauge-reader](https://github.com/goodyork/analog-gauge-reader)：README 描述 YOLO 检测和四关键点、OCR 估计刻度及单位，并提供手动确认；源码仓库声明 MIT。比赛开始后要求自主执行，应事先标定，不依赖运行时人工确认；权重及数据不随仓库提供，需分别核实来源与许可。
- [OpenCV Hough 直线说明](https://docs.opencv.org/4.x/d9/db0/tutorial_hough_lines.html)：提供 `HoughLines` / `HoughLinesP`，可用于指针候选提取，但线段还可能来自刻度、文字或反光。


## 8. 标定模板加几何推算：已有实验记录

可行的前提是比赛表盘样式固定，且能通过标定得到每组刻度的中心、角度、半径及图像到模板的对应关系。标准温湿度表不保证刻度均匀、两针同心或印刷没有误差；使用现有实拍及实物逐项核验。标注刻度可以从已验证模板投影得到，不必逐帧检测每条刻度，但必须先确认当前画面与模板匹配，不能把模板生成点冒充实际检测结果。

1. **建立模板**：以正视表盘为坐标系，分别登记温度与湿度轴心 `(cx, cy)`、每个刻度值、角度和半径，记录针的活动扇区。若实测 N 个间隔等角，令第 i 个角度 `θi = θ0 + i(θ1-θ0)/N`，刻度点为 `(cx+r cos θi, cy+r sin θi)`；图像 y 轴向下，角度方向需与标定约定一致。非等间隔或多圈刻度直接保存每条刻度的实测坐标，不套均匀公式。
2. **对齐图像**：首版固定相机和观察姿态，使用人工标定 ROI；姿态变化时使用表盘平面上至少四个可靠对应点估计透视变换，检查对应点重投影误差和模板是否匹配。轴心及刻度坐标经逆变换回原图逐个圈出；模糊、遮挡或对齐失效时标记未知，不输出臆造标记。不能仅把椭圆拉圆当作完整透视校正。
3. **提取两根针**：在矫正后的各自扇区，遮蔽已知刻度/文字区域，先用灰度、阈值或边缘及线段检测，筛选靠近对应轴心、长度和方向合理的线段；分别检查针尖、短针尾、反光、文字与另一根针的干扰。也可沿候选角度从轴心向外统计线像素支持度；若多个候选难以区分或支持不足，该项输出未知。模板几何只能提供中心和可能方向，指针实际朝向仍须从当前帧获得。
4. **读数与绘制**：以 `atan2(y_tip-cy, x_tip-cx)` 求针角，按标定方向展开跨角边界，再在相邻已知刻度之间插值。连续估计与规则允许整数分别记录；规则只给出了局部示例，其他取整口径需确认。用同一套变换将针、轴心及每个模板刻度回映原图，逐项标注；温湿两项独立保存状态和单位。
5. **合成几何检查**：程序生成可配置的双针合成表盘，已知轴心、刻度和针角作为真值；先测均匀与非均匀刻度、顺/逆时针、跨角边界、不同轴心，再加入透视、噪声、反光、遮挡和针尾，检查坐标回映、读数误差及失败状态。合成结果只能验证几何和流程，不能证明真实表盘可识别。
6. **实拍核对**：利用现有实拍照片和视频，人工标每个刻度、两针轴心及尖端，比较均匀公式与逐点模板误差；选足够稳定的视角标定和定位方法。按独立批次测读数正确率、指针误检、未知率、刻度漏圈/错圈和耗时，验证共享几何链的实物适用范围。

## 9. PDF 单图指针实验（2026-11-06）

从仓库 `国赛规则说明.pdf` 第 15 页提取内嵌的 641×672 温湿度计 JPEG，原样本位于忽略目录 `datasets/raw/meter/pdf/page15-005.jpg`。可以在仓库根目录使用 Poppler 的 `pdfimages -f 15 -l 15 -j 国赛规则说明.pdf datasets/raw/meter/pdf/page15` 重新提取；需先创建目标目录。第 005 张为本实验使用的温湿度表。

实验入口为 `lab/features/meter/inference/scripts/read_meter.py`，导入共享核心 `aec_vision.meter`；`lab/features/meter/inference/config/pdf_page15.json` 的轴心、扇区和半径是对这张原图的人工标定。安装 Python 的 OpenCV 和 NumPy 后，在仓库根目录运行：

```powershell
python lab/features/meter/inference/scripts/read_meter.py datasets/raw/meter/pdf/page15-005.jpg --template datasets/raw/meter/pdf/page15-005.jpg --config lab/features/meter/inference/config/pdf_page15.json --ticks lab/features/meter/inference/config/pdf_ticks.json --output lab/features/meter/inference/outputs/pdf_overlay.png
python lab/features/meter/inference/tests/test_needle.py
```

算法在各自标定扇区中逐角度统计靠近轴心的暗色径向线支持度，找到方向后沿该方向延长估计端点。此图得到温度针 -62.5°、湿度针 152°（图像坐标，向右为 0°、顺时针为正），绘制结果目视与两针方向一致；端点是暗线延伸估计，非人工核准真值。合成针角及纯白、纯黑帧检查通过。实验在 Windows Python 3.12、OpenCV 5 下进行，Ubuntu 20.04 / ROS Noetic 环境尚未验证。

该样本同时用于标定和观察，结果只用于单图流程检查；暗线支持度不是概率，实物标定迁移与误检需独立图片验证。模板匹配、逐刻度标注和读数的实现及实验范围见下文。


## 10. 模板匹配与逐刻度标注实验

单图入口以 `--template` 指定标定模板，通过 ORB 特征匹配和 RANSAC 估计模板到输入图的单应矩阵；匹配数量、内点比例、覆盖范围、投影几何或近似表盘边界可见性未通过时返回未知并不绘制刻度。匹配成功后将输入图映射到模板坐标识别指针，再将指针和 `--ticks` 提供的刻度端点映回原图。刻度以亮绿色线段显示，指针保持红/蓝。

`pdf_ticks.json` 记录根据 PDF 原图估计的温度 81 条和湿度 51 条刻度线，部分端点受透视、遮挡和图像分辨率影响，尚未逐条人工核实；绿色线条是标定模板投影，不代表逐条实时检测成功。应在实物上逐条校准，核对完整率和偏差，不能凭此宣称比赛图像标注准确。模板以 PDF 图片为基准，ORB 特征限定在中心椭圆并要求内点覆盖至少三个象限；模板必须是大致居中的表盘，椭圆内仍可能含背景或指针。验证覆盖原图及其缩放平移、合成纹理的旋转透视、空白图和移除表盘但保留背景的图；独立拍摄下的可靠性及模板不匹配时的误识别仍待评估；本图遮挡与针移动测试见下文。

## 13. 无固定模板坐标的 OpenCV 原型（已有实验记录）

核心 `ws/src/aec_vision/src/aec_vision/meter_auto.py` 使用霍夫圆提取大圆及下方小圆候选，径向暗线扫描寻找指针、刻度和最大空白角隙，以得到弧段两端候选。相对尺寸、下方双圆结构、不同环带及灰度阈值均是从 PDF 样本出发的实验假设；圆心与刻度坐标由当前图像估计。外圆是温度、小圆是湿度也只是待现场确认的拓扑假设。

运行 `python lab/features/meter/inference/scripts/auto_meter_example.py datasets/raw/meter/pdf/page15-005.jpg --output lab/features/meter/inference/outputs/auto_meter.png`。绿色线是未经核实的刻度候选、黄圈是弧两端候选（A/B，未知哪端最小），红/蓝线分别为大小表针。默认不推断数值递增方向，故两项读数为未知；加入 `--assume-clockwise` 才假设弧起点为最小值、沿图像顺时针递增，并尝试按均匀角度换算。温度范围 -30～50 °C、湿度 0～100 %RH 在脚本顶部配置；不代表量程或方向已现场核准。候选角间距的第90百分位与第10百分位之比超过 1.45 时拒绝等角读数；该阈值是样本实验启发式，不能证明其余场景真实均匀。

本机 PDF 图上外圆心约 (321.5,351.5)、内圆心约 (323.9,494.6)，指针角度约 -62°、149.5°；温度检出 72 条刻度候选、湿度 54 条，存在漏检与误检，不能称逐刻度正确。方向假设下温度约 20.37 °C 为未核实估计；湿度候选间距未通过等角检查，返回未知。若忽略该检查，以角度全弧线性换算约 72.96 %RH，与此前同图逐候选刻度插值约 65.69 %RH 相差约 7.27 个百分点；两者都不是独立真值，不能用其中一个宣称正确。

将原图缩小为 0.75 倍时仍检出两针候选；亮度降到 50% 后两针返回未知；图像旋转 10° 时刻度弧未稳定检出；纯白图返回未知。上述都只是单样本变换，无法证明实际小车效果。需进一步解决两个轴心独立定位、纹理误报、缺漏刻度、视角影响、端点语义和真实图片评测，方可用于比赛。
