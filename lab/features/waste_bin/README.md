# 垃圾桶状态与投放识别

规则：第 11–12、23、25 页；四个桶的开闭每个 1 分、分类判断每个 1.5 分，共 10 分。示例：“可回收垃圾桶状态为打开，垃圾桶里的垃圾为 XX，投放正确。”

### 目标与覆盖：垃圾桶开闭 `waste_bin_state`

- **必须学习什么：**定位垃圾桶并判断开/闭；学习桶体、桶口和盖板的相对关系。
- **不能依赖什么：**用桶色猜开闭、固定桶位、只看正面、固定相邻关系。
- **直接安排的状态与组合：**四色桶 × 开/闭 × 不同桶位和背景 × 单桶/多桶 × 偏航、明暗、饱和度；加入邻桶遮挡、低视点及贴纸变化。
- **基底、负例与标注：**四色桶实拍、开闭视频及可用 Blender 桶模型；结合直接实拍。空负例由画面证实无任务范围内的桶，方箱和相似色物体可作干扰。主体桶及范围内其他可识别的桶均标可见框和开闭状态。远处非主体且明确在范围外的桶可保留在背景中。范围内盖态不可判时记未知。以桶为主体的帧从桶开闭任务的常规合成底图池排除，标签完整时用作直接目标样本。底图中非主体且仍在识别范围内的桶要完整标注，合成后保留并更新其标签。[标签、空间与用途资格](../../../docs/DATASET_DESIGN.md#标签空间与用途资格)

### 目标与覆盖：垃圾贴纸 `waste_sticker`

- **学习目标**为定位贴纸并识别固定的 **24 种物品图案**。贴纸可以独立摆放、贴在其他表面或贴在桶面。
- **干扰因素**包括载体、背景和桶身固有分类标志。后者可用于检查相似图案误报。
- **组合与配额**按 24 类的有效可见实例均衡，覆盖 1–3 个可见桶及 0–3 张可见贴纸，每桶至多一贴。制作时轮换大小、面内位置、旋转、正斜视角、光照和部分遮挡。桶体颜色随场景变化，用于现场桶类别与归属。[分集与来源设计](../../../docs/DATASET_DESIGN.md#垃圾贴纸数据设计)
- **实拍、合成与标注**按固定 24 类图案及当前任务范围记录可辨物品贴的类别与可见框。桶面实拍用于覆盖赛场外观，并可另记桶归属供现场投放联调。
