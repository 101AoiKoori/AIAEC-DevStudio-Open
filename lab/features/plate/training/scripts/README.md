# 车牌场景脚本

`inspect_arena_plate.py` 检查车牌场景副本。`render_plate_arena_pilot.py` 和 `render_plate_arena_measured_batch.py` 在场景副本中拟合现场车体裁片；车体尺寸、位置和遮挡状态未测量。

`render_plate_empty_scene.py` 创建 36 × 24 cm 的牌面和示意支架，使用 46 × 18 像素的现场裁片贴图及 Cycles OPTIX 渲染。拟合时核对裁片与牌面比例。 [现行车牌方案](../../README.md) · [车牌试验记录](../../../../../docs/research/PLATE_DUAL_OCR.md)
