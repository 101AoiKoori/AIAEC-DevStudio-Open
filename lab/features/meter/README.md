# 站房温湿度表与数显电表读取

按用户确认的现场范围，站房识别对象为同一表盘中的温度计与湿度计。输出图需要逐一圈出所有刻度，标出指针和原点。温度、湿度各7分，共14分。站房另有位于表盘下方的数显电表，按用户确认增加读数任务。

用户确认拍摄期间仪表指针静止；首版在观察位置拍摄一张照片，使用同一帧完成温度、湿度读取和标注，以及下方电表读数。单项不能可靠判读时输出未知。

状态含义见 [需求状态约定](../../../docs/PERCEPTION_DEVELOPMENT.md#需求状态与提醒)。标签描述本条当前工作状态；已明确的规则不等于实现完成。

## 需要实现

- `[待解决]` METER-R03：两项结果有独立状态。某针无法定位或其刻度映射无效时，该项输出未知；不得用另一指针、旧帧或默认值填充。

- `[待解决]` METER-R04：按站房观察机位标定电表显示窗 ROI，用 OCR 读取数字和小数点。电表读数有独立有效状态，显示窗失配、反光、过曝或字符无法确认时输出未知。数显电表沿用现有图像与 OCR 能力，无独立训练检测模型。

## 初始开发流程

仪表采用单个双针 YOLO Pose 模型定位表盘、温湿两针及其轴心和刻度端点；赛前人工标定量程及逐刻度映射，使用合成样本训练，并覆盖旋转、俯仰、偏航和反光；运行时以表盘上可验证的共面对应点计算透视配准，再由 OpenCV 几何完成读数和图像标注。单帧不足以可靠判断时该项输出未知。模型、配准精度、完整逐刻度标注和整套模型加载预算均待实物及目标车验收。

在 `ws/src/aec_vision/src/aec_vision/meter.py` 开发共享推理核心；实验与训练留在 `lab/features/meter/`，共用该推理核心。使用已有仪表手持、小车摄像头照片及固定读数视频核对实物，也可作为训练素材或合成场景基底；记录实拍及其派生物的已知来源和跨集合复用范围，验证两项读数、全刻度圈选、双指针和原点标注、坐标回映、未知状态及端到端耗时。详细采集表和实验步骤见 [仪表视觉方案](../../../docs/research/METER_VISION.md)。现有素材的读数真值、相机条件和 ROS/实车效果需逐项核实。
