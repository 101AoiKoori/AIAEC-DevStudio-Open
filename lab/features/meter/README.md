# 站房温湿度表与数显电表读取

站房读取同一表盘上的温度与湿度，以及表盘下方数显电表的读数。温湿度输出图逐一圈出所有刻度，标出各自指针和原点。温度、湿度各 7 分，共 14 分。

拍摄期间仪表指针静止。在观察点拍摄一张照片，从同一帧读取三项结果并完成温湿度标注。无法可靠判读的单项输出未知。

采样与处理按[定点正对采样](../../../docs/PROJECT_DIRECTION.md#定点正对采样)执行。

事项标签见[需求状态约定](../../../docs/PERCEPTION_DEVELOPMENT.md#需求状态与提醒)。

### 目标与覆盖：温湿度表 `meter`

- **必须学习什么：**定位双针表盘，识别温度、湿度两组关键点，依据量程和刻度映射读数；数显电表沿用 ROI＋OCR。
- **不能依赖什么：**固定读数、固定表盘位置、正面视角、固定光影和背景。
- **直接安排的状态与组合：**温针位置 × 湿针位置 × 表盘距离和位置 × 轻度偏航 × 明暗、饱和度；加入玻璃反光、合理遮挡、无表场景。
- **基底、负例与标注：**表盘实拍及双针 Blender 模型＋站房背景；结合直接实拍。圆灯、圆牌、仅电表画面作干扰；标表盘和两组轴心、针尖、量程端点。

## 初始开发流程

仪表先定位表盘，再识别双针八个关键点，并用几何关系计算温湿度读数；表盘定位与八点识别采用一个还是两个模型待专项设计；赛前以 YAML 配置量程及逐刻度映射，使用合成样本训练，并覆盖旋转、俯仰、偏航和反光；运行时以表盘上可验证的共面对应点计算透视配准，再由 OpenCV 几何完成读数和图像标注。单帧不足以可靠判断时该项输出未知。模型、配准精度、完整逐刻度标注和整套模型加载预算均待实物及目标车验收。

在 `ws/src/aec_vision/src/aec_vision/meter.py` 开发共享推理核心；实验与训练留在 `lab/features/meter/`，共用该推理核心。使用已有仪表手持、小车摄像头照片及固定读数视频核对实物，也可作为训练素材或合成场景基底；记录实拍及其派生物的已知来源和跨集合复用范围，验证两项读数、全刻度圈选、双指针和原点标注、坐标回映、未知状态及端到端耗时。详细采集表和实验步骤见 [仪表视觉方案](../../../docs/research/METER_VISION.md)。现有素材的读数真值、相机条件和 ROS/实车效果需逐项核实。
