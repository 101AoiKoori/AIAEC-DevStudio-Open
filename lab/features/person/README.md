### 目标与覆盖：人物 `person`

- **必须学习什么：**定位当前画面中正面及类别可辨的人偶立牌，区分社区与非社区；现场按观察点过滤并逐人计数。
- **不能依赖什么：**固定街景、固定位置、只有一个人、只有正面居中且光线一致。
- **直接安排的状态与组合：**社区/非社区 × 单人/多人 × 不同街景和位置 × 正面及可辨的轻度偏航 × 明暗、饱和度；加入人物互挡、人车遮挡、不同大小（合成放置与现场过滤见 PERSON-MIN-SCALE）。
- **基底、负例与标注：**人物立牌实拍或图案＋街景实拍；结合直接实拍。正面及类别可辨的立牌逐个标可见框；白背作硬负例，同框保留可辨正面的标签。
